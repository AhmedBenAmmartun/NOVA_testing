# CLAUDE.md — NOVA

This project's real, maintained documentation lives in **`DEVELOPMENT.md`**
(layout, run/test commands, non-obvious gotchas, and rules) and
**`ROADMAP.md`** (current status, phases, what's done vs. in progress).

This file is deliberately a thin pointer, not a copy. Claude Code
auto-loads whichever file is literally named `CLAUDE.md` at the project
root, but `DEVELOPMENT.md` is the one that actually gets kept current —
duplicating its content here would just go stale again (that already
happened once: a stray pre-rename `CLAUDE.md` fed outdated info — "38
tools" instead of the real 54, no mention of the guardian/integrations
work — into a session on 2026-07-26).

Read `DEVELOPMENT.md` and `ROADMAP.md` before doing anything else in this
repo.
